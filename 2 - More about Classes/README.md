## Section 2: Review Questions and Exercises
### 1. What does ADT stand for?

Abstract Data Type.

### 2. Which of the following must a programmer know about an ADT to use it?

#### a) What values it can hold
#### b) What operations it can perform
#### c) How the operations are implemented

a and b

### 3. The two common programming methods in practice today are ____ and ____ .

Procedural and object-oriented.

### 4. ______ programming is centered around functions, whereas ______ programming is centered around objects.

Procedural, object-oriented

### 5. An object is a software entity that combines both ____ and ____ in a single unit.

Data (attributes) and procedures (methods)
