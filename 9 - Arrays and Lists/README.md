## Section 2: Review Questions and Exercises

### 1. Describe the two parts of a node.

Data and a pointer pointing to the next node's memory address

### 2. What is a list head?

The head is a pointer that points to the first node in the linked list. It serves as the entry point to the entire data structure. If the head pointer is nullptr, it shows that the linked list is currently empty.

### 3. What signifies the end of a linked list?

The end of a singly linked list is signified when the pointer pointing to the next node of the last node points is nullptr.

### 4. What is a self-referential data structure?

A self-referential data structure is a struct that contains a pointer or reference to an instance of itself.
